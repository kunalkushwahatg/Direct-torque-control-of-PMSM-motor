# Project history

The public repository contains the final experiments, documentation, reports,
and model screenshots. It does **not** include the early development models,
superseded scripts, or debugging screenshots.

Those files remain recoverable from earlier Git history if needed. The current
working tree is intentionally limited to:

- `experiments/` — final experiment folders
- `docs/` — runbook, changelog, lessons, audits, screenshots
- `reports/` — written reports
- `tools/` — shared helpers
- `templates/` — experiment README template

The `literature/` folder is local-only because the source papers are not
redistributed here.
