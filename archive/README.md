# Archive

This folder is development history, not the current model. It keeps earlier model
versions, replaced scripts, and debugging screenshots so the work can be traced — it is
not needed to reproduce the published results.

Use the active code in [`../experiments/`](../experiments/README.md) and the operating
manual in [`../docs/RUNBOOK.md`](../docs/RUNBOOK.md).

To find where an older file went, see [FILE_MAP.md](../docs/FILE_MAP.md). Nothing was
deleted; everything was moved.

- `00_` – `03_` — dated snapshots from the early and mid-development stages.
- `04_superseded_scripts` — scripts replaced by the current experiment scripts.
- `_generated_cache` — Simulink caches that can be regenerated or deleted.
